SupriAI Documentation

SupriAI is an AI-powered learning companion Chrome extension that automatically tracks, analyzes, and enhances your learning journey through intelligent insights and personalized recommendations.

AI-Powered

Gemini AI integration for intelligent content analysis, summarization, and personalized recommendations.

Smart Analytics

Comprehensive learning analytics with engagement scoring, topic tracking, and progress visualization.

Auto Learning

Automatic content classification, skill assessment, and learning path generation.

Smart Notifications

Intelligent reminders, study suggestions, and achievement celebrations.

Quick Start: Install the Chrome extension, start the backend server, and begin browsing educational content. SupriAI will automatically track and analyze your learning!

Installation

Prerequisites

  • Python 3.8+ with pip
  • Google Chrome browser
  • Gemini API Key (optional, for AI features)

Backend Setup

Terminal
# Navigate to backend directory
cd backend

# Install dependencies
pip install -r requirements.txt

# Set up environment variables
echo "GEMINI_API_KEY=your_api_key_here" > .env

# Start the server
python app.py

Extension Installation

  1. Open Chrome and navigate to chrome://extensions
  2. Enable "Developer mode" in the top right
  3. Click "Load unpacked" and select the SupriAI folder
  4. The extension icon will appear in your toolbar
Success! Once both the backend and extension are running, SupriAI will automatically begin tracking your learning activities.

Analytics API

Core endpoints for retrieving learning analytics and statistics.

GET /get_analytics

Get comprehensive analytics including total time, topic distribution, weekly trends, and recommendations.

GET /api/analytics/topics

Get detailed breakdown of learning by topic with session counts and engagement scores.

GET /api/analytics/trends

Get learning trends over time for visualization in charts.

Content Script

The content script tracks user engagement on web pages.

Tracked Metrics

  • Duration: Time spent on page
  • Scroll Depth: How far user scrolled
  • Clicks: Number of interactions
  • Mouse Movement: Total mouse distance
  • Content: Extracted page text for classification

Configuration

content.js
const CONFIG = {
    MIN_DURATION: 5,           // Minimum seconds before logging
    SYNC_INTERVAL: 30000,      // Sync every 30 seconds
    MAX_CONTENT_LENGTH: 5000,  // Max content to extract
    USE_AI_LOG: true,          // Use AI-enhanced logging
    EXTRACT_METADATA: true     // Extract page metadata
};

Background Service

The background service worker handles all backend communication and automation.

Automation Alarms

  • retrySync - Sync offline logs (every 5 min)
  • historySync - Sync Chrome history (every 30 min)
  • aiInsights - Auto-fetch insights (every 60 min)
  • weeklyReport - Generate weekly report (Sundays)
  • smartNotifications - Check for reminders (every 30 min)
