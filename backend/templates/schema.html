Detailed Table Definitions

Click on any table to expand and view complete column definitions

users

Core Table

Central user table storing account information, profile data, streaks, and gamification points. All other tables reference this via user_id foreign key.

Column Type Constraints Default Description
id INTEGER PRIMARY KEY AUTOINCREMENT Unique user identifier
email TEXT UNIQUE - User email address
display_name TEXT - - Display name shown in UI
avatar_initial TEXT - - Initial letter for avatar
plan_type TEXT - 'free' Subscription plan type
streak_days INTEGER - 0 Current learning streak
total_points INTEGER - 0 Gamification points earned
settings TEXT - '{}' JSON settings object
created_at TEXT - CURRENT_TIMESTAMP Account creation time

learning_logs

Activity Tracking

Primary activity tracking table that stores every learning session. Captures URL, duration, engagement metrics, and AI-classified topic for comprehensive analytics.

Column Type Constraints Default Description
id INTEGER PRIMARY KEY AUTOINCREMENT Unique log identifier
user_id INTEGER FOREIGN KEY 1 References users(id)
url TEXT NOT NULL - Page URL visited
title TEXT - - Page title
topic TEXT - - AI-classified topic
confidence REAL - 0 Classification confidence %
duration REAL - 0 Time spent in seconds
max_scroll REAL - 0 Max scroll depth %
clicks INTEGER - 0 Number of clicks
mouse_distance REAL - 0 Mouse movement distance
engagement_score REAL - 0 Calculated engagement 0-100
content_preview TEXT - - Extracted page content
timestamp TEXT - CURRENT_TIMESTAMP Session timestamp

goals

Productivity

Learning goals with progress tracking. Supports different goal types (daily, weekly, custom) with target values and completion status.

Column Type Constraints Default Description
id INTEGER PRIMARY KEY AUTOINCREMENT Goal identifier
user_id INTEGER FOREIGN KEY 1 References users(id)
title TEXT NOT NULL - Goal title
goal_type TEXT - 'weekly' daily/weekly/monthly/custom
target_value INTEGER - 0 Target to achieve
current_value INTEGER - 0 Current progress
unit TEXT - 'count' Unit of measurement
is_completed INTEGER - 0 Completion flag (0/1)

tasks

Todo Management

Task management with priority levels, due dates, time estimates, and recurring task support. Integrates with Pomodoro sessions.

Column Type Constraints Default Description
id INTEGER PRIMARY KEY AUTOINCREMENT Task identifier
user_id INTEGER FOREIGN KEY 1 References users(id)
title TEXT NOT NULL - Task title
priority TEXT - 'medium' low/medium/high/urgent
status TEXT - 'pending' pending/in_progress/completed
estimated_minutes INTEGER - 30 Estimated time
is_recurring INTEGER - 0 Recurring flag

pomodoro_sessions

Focus Timer

Tracks Pomodoro focus sessions including focus time, breaks, and links to associated tasks for productivity analytics.

Column Type Constraints Default Description
id INTEGER PRIMARY KEY AUTOINCREMENT Session identifier
user_id INTEGER FOREIGN KEY 1 References users(id)
task_id INTEGER FOREIGN KEY - References tasks(id)
session_type TEXT - 'focus' focus/short_break/long_break
duration_minutes INTEGER - 25 Planned duration
actual_duration INTEGER - 0 Actual time spent
status TEXT - 'completed' Session status

bookmarks

Saved Resources

Saved learning resources with topic classification, reading time estimates, and completion tracking.

Column Type Constraints Default Description
id INTEGER PRIMARY KEY - Bookmark ID
user_id INTEGER FK 1 User reference
url TEXT NOT NULL - Resource URL
title TEXT - - Resource title
resource_type TEXT - 'article' Type classification
is_read INTEGER - 0 Read status

settings

User Preferences

User preferences including tracking toggles, dark mode, notification settings, and daily learning goals.

Column Type Constraints Default Description
user_id INTEGER UNIQUE FK 1 User reference
tracking_enabled INTEGER - 1 Enable tracking
dark_mode INTEGER - 0 Dark mode toggle
notification_enabled INTEGER - 1 Notifications toggle
daily_goal_minutes INTEGER - 60 Daily goal
