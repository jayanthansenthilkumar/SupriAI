# SupriAI - Complete Features Documentation

## 🎯 Overview
SupriAI is an AI-powered Learning Analytics Chrome Extension with comprehensive learning management, AI assistance, and personalized recommendations.

---

## 📚 **MY LIBRARY PAGE**

### Features
- **Learning History Tracking**: View all your browsing history with engagement metrics
- **Smart Filtering**: Filter by All, Bookmarks, Recent, Favorites
- **Search Functionality**: Quick search across titles, URLs, and topics
- **Bookmarks Management**: Save and organize important resources
- **CSV Export**: Export your learning history for external analysis

### Statistics
- Total Items: Total number of tracked learning sessions
- Bookmarks: Number of saved bookmarks
- This Week: Learning items from the past 7 days
- Top Topic: Most frequently visited topic

### How to Use
1. **View History**: All your browsing activities are automatically tracked
2. **Bookmark Items**: Click the bookmark icon on any history item
3. **Add Manual Bookmarks**: Click "Add Bookmark" button and fill in the form
4. **Search**: Use the search bar to filter history by keywords
5. **Export**: Click "Export CSV" to download your data
6. **Delete**: Remove unwanted items from your history

---

## 📝 **REVIEWS / NOTES PAGE**

### Features
- **Create Learning Notes**: Document learnings, tips, problems, and ideas
- **Category System**: Organize notes by type (Reflection, Tip, Problem, Resource, Idea)
- **Tag Support**: Add tags for better organization
- **Search & Filter**: Find notes by content, title, or category
- **Edit & Delete**: Manage your note collection

### Note Categories
- **Reflection**: Daily/weekly learning reflections
- **Tip/Trick**: Useful tips discovered
- **Problem Solved**: Solutions to challenges faced
- **Resource Note**: Notes about learning resources
- **Idea**: New ideas and insights

### How to Use
1. **Create Note**: Fill in the form at the top of the page
   - Enter title (optional)
   - Select category
   - Write content
   - Add tags (comma-separated)
2. **Save**: Click "Save Note" button
3. **Search**: Use search bar to find specific notes
4. **Filter**: Use category dropdown to filter by type
5. **Edit**: Click edit icon on any note card
6. **Delete**: Click delete icon to remove notes

## 🎯 **GOALS PAGE**

### Features
- **Active Goals Tracking**: Set and monitor learning goals
- **Progress Visualization**: Progress bars for each goal
- **Streak Counter**: Track daily learning streaks
- **Points System**: Earn points for completing goals
- **Achievement System**: Unlock badges and achievements
- **Weekly Statistics**: View goals completed, learning hours, and sessions

### Goal Types
- **Daily**: Goals to complete each day
- **Weekly**: Weekly learning targets
- **Monthly**: Long-term monthly goals
- **Custom**: Flexible custom timeframes

### How to Use
1. **Create Goal**: Click "New Goal" button
   - Enter goal title (e.g., "Read 5 articles")
   - Select frequency (daily/weekly/monthly/custom)
   - Set target value (e.g., 5)
   - Add unit (e.g., "articles", "minutes", "sessions")
2. **Update Progress**: Click "Update Progress" on any active goal
   - Enter the amount to add to current progress
   - Goal automatically completes when target is reached
3. **View Stats**: Check streak days, total points, and weekly statistics
4. **Achievements**: Automatically unlock as you progress
5. **Delete**: Remove goals you no longer want to track

### Achievements System
Achievements are automatically unlocked based on your activity:
- First Steps: Complete your first learning session
- Week Warrior: Maintain a 7-day streak
- Century Club: Accumulate 100 total hours
- Knowledge Seeker: Complete 50 learning sessions
- And many more...

## 🚀 **HOW IT ALL WORKS**

### Data Collection
1. Chrome extension tracks your browsing automatically
2. URLs are classified by topic using ML/NLP
3. Engagement scores calculated based on time and interactions
4. Data synced to backend every 30 minutes

### AI Engine
- **NLP Processor**: Analyzes content with TF-IDF, sentiment analysis, entity extraction
- **Deep Learning Engine**: Pattern recognition, user behavior classification
- **Chat Assistant**: Intent classification, context-aware responses
- **Resume Builder**: Skill extraction, proficiency calculation

### Backend API
- Flask server on http://localhost:5000
- SQLite database with 18+ tables
- 60+ REST API endpoints
- Real-time data processing

## 🔄 **DATA SYNC**

- **Automatic Sync**: Every 30 minutes

- **Conflict Resolution**: Latest data takes precedence

## 🔒 **PRIVACY & SECURITY**

- All data stored locally in SQLite database
- No data sent to external servers (except localhost)
- URLs and titles are the only tracked information
- You can delete any tracked data anytime
- Export and backup your data regularly
