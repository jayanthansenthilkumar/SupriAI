IntellicAI Documentation

AI-Powered Browsing Intelligence System with real-time Chrome history analysis, automated productivity forecasting, offline IndexedDB sync, and 10 Machine Learning & Deep Learning algorithms.

System Architecture

IntellicAI is structured into 4 decoupled, high-performance layers: Client Extension, Analytics Dashboard, Express API Gateway, and Python ML Engine.

🧩 Chrome Extension Manifest V3

Real-time tab activity tracking, active duration logger, Chrome history importer, and offline IndexedDB (IntellicAI_DB) sync.

⚡ Express API Gateway Port 3001

Node.js Express server managing SQLite database (intellicai.db) with dual driver fallback (better-sqlite3) and REST APIs.

🐍 Python Flask ML Engine Port 5000

Flask API hosting 10 Machine Learning and Deep Learning models built with scikit-learn, scipy, numpy, and joblib.

System Execution & Quickstart Guide

1. Seed Database & Train ML Engine 
# Navigate to server directory
cd server

# Seed 4,700+ dummy browsing records into SQLite
node seed.js

# Train and serialize all 10 ML & Deep Learning models
python train_models_with_dummy.py
2. Launch Full Stack Server (Vite + Express + Python) 
# Run from root project directory
npm run dev

# Services Started:
# - Vite React Dashboard  --> http://localhost:5173
# - Express API Gateway   --> http://localhost:3001
# - Python Flask Engine   --> http://127.0.0.1:5000
3. Load Chrome Extension in Browser 
1. Open Chrome and navigate to chrome://extensions
2. Enable Developer mode (top right toggle)
3. Click Load unpacked
4. Select the public folder inside the IntellicAI project root
5. Pin the IntellicAI extension icon to your browser toolbar
