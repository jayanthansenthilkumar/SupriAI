API Documentation

Open API Root

Developer Reference

Base URL: http://localhost:5000
All API responses return JSON. Authentication is currently open for local extension use.

Status & Health

GET /health Server health check
Response
{ "service": "SupriAI Backend", "status": "running", "timestamp": "2026-01-11T17:35:00", "version": "1.0.0" }
GET /api/status Database connection status and stats
Response
{ "database": "connected", "status": "online", "timestamp": "2026-01-11T17:35:00", "total_sessions": 142 }

Activity & Analytics

POST /log_activity Log a single learning activity

Records a user's browsing activity, classifies content, and calculates engagement.

Request Body
content string Optional Page classification content
title string Required Page title
url string Required Page URL
duration integer Required Time spent in seconds
Response
{ "confidence": 0.85, "engagement_score": 75, "log_id": 101, "recommendation": "Try a related tutorial on...", "status": "success", "topic": "Python" }
GET /get_analytics Get dashboard analytics summary
Query Parameters
days integer Optional Default: 7

Tasks & Todos

GET /api/tasks List all tasks
Query Parameters
status string Optional Filter by 'pending', 'completed'
POST /api/tasks Create a new task
Request Body
{ "title": "Complete Python Project", "description": "Finish the detailed API implementation", "due_date": "2026-01-20", "priority": "high", "tags": ["coding", "python"] }

History & Library
