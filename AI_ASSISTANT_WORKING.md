## How to Use:

### 1. Start Backend (if not already running):
```bash
cd backend
python app.py
```

### 2. Open Dashboard:
- Click SupriAI extension icon
- Click "Open Dashboard"
- Navigate to "AI Assistant" in sidebar

### 3. Start Chatting:
- Type any question or use suggestion prompts
- AI will respond with intelligent, context-aware answers
- Chat history is automatically saved
